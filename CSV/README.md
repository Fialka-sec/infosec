### Анализ CSV-файлов на базе Streamlit

---

#### Описание

Данное приложение предназначено для быстрого анализа таблиц в формате CSV. Пользователь может загрузить файл, ознакомиться с данными (отображение первых строк), выбрать интересующие его столбцы и получить статистические показатели: среднее значение, медиану и стандартное отклонение. Также предусмотрена визуализация данных: построение графиков пар столбцов (линейных или рассеяния), а также графиков распределения (гистограмма, кривая плотности, столбчатая диаграмма). Для дата- и временных данных реализована особая обработка. Есть возможность сохранить текущий график как изображение.

Алгоритмы, используемые в приложении, включают:
- определение типа данных столбца (числовой, дата, текст),
- расчет статистических показателей с помощью pandas,
- построение графиков с помощью seaborn и matplotlib,
- кеширование данных для ускорения работы.

#### Установка зависимостей

Для запуска приложения потребуется установить Python и необходимые библиотеки:

```bash
pip install streamlit pandas numpy matplotlib seaborn

### Шаги
- Скачайте Python (если еще не установлен).
- Откройте командную строку или PowerShell
- Выполните команду выше для установки необходимых библиотек.
- Скопируйте предоставленный файл app.py в папку.

---

### Запуск

1. Перейдите в командную строку или PowerShell в папку с вашим файлом:
cd путь\к\папке
2. Запустите приложение командой:
streamlit run "C:\Users\gerre\OneDrive\Рабочий стол\app csv.py"
3. В браузере откроется интерфейс анализа данных.
